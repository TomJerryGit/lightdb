## 修复的 7 个回归（beta.152）

根因：D3 引入的 `_coerce_trigger_row()` 对 `INSERT` 行做了全列 `coerce`，
把内部哨兵 `_OMITTED`（“该列未提供且无 DEFAULT”）通过其 `__str__` 变成
普通字符串 `'NULL'`，导致：

- 缺失列被写成字符串 `'NULL'`（`test_metadata_honesty` / 预处理语句元数据失败）；
- UNIQUE 列（如 email）所有缺失值都变成 `'NULL'` → 1062 Duplicate entry
  （`test_auto_increment_p6` 4 个用例、`test_alter_add_drop_column` 失败）。

另外 D3 让逻辑 dump 也导出 `AUTO_INCREMENT`，而 SHOW CREATE 后处理又追加一次
→ 出现两个 `AUTO_INCREMENT`。修复：

1. `_coerce_trigger_row` 跳过 `_OMITTED` 哨兵（保留给 `Table._insert_locked` 解析成 NULL）；
2. SHOW CREATE 后处理判重，已有 `AUTO_INCREMENT` 不再追加；
3. DDL 渲染顺序对齐 MySQL 习惯（自增主键列：`NOT NULL AUTO_INCREMENT PRIMARY KEY`；
   非主键自增列：`UNIQUE AUTO_INCREMENT`）。
