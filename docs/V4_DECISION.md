# LightDB v4.0 技术决策文档

**决策日期**：2025-02-15
**决策范围**：v4.0 性能优化技术路线
**决策者**：LightDB 架构组

---

## 一、背景

### 现状

- **v3.0 性能**：MySQL 5.7 的 80%
- **单核瓶颈**：6500 QPS（MySQL 8000）
- **多核瓶颈**：8 核仅 8200 QPS（GIL 限制）
- **OLAP**：不支持列式扫描

### 目标

- **v4.0 性能**：MySQL 5.7 的 **120%**
- **单线程**：12,000 QPS
- **多线程**：80,000 QPS（8 核）
- **OLAP**：1M rows/s

---

## 二、诊断结论

### 2.1 性能热点分布

| 类别 | 耗时占比 | 说明 |
|------|:--------:|------|
| B+Tree | 25% | 纯 Python 指针操作 |
| 行序列化 | 20% | JSON 转 Python |
| 页操作 | 15% | 字节读写 |
| 执行器 | 10% | 火山模型 |
| 网络 | 8% | MySQL 协议 |
| 其他 | 22% | 分散 |
