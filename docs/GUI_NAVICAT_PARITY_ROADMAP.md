# LightDB Studio 深度对标 Navicat：功能细节清单与优化路线（2026-10-21）

> 依据：[`COMPETITIVE_ANALYSIS_NAVICAT_MYSQL.md`](COMPETITIVE_ANALYSIS_NAVICAT_MYSQL.md)
> 的本机实测（Navicat for MySQL 10.0.11 + MySQL 5.0.51b）与仓库源码。
> 目标：**不追 Navicat 全功能，而是把高频 20% 做到"细节不输、体验更现代"**。
> 本文同时是执行看板：G1/G2/G3 + E1/E2（引擎依赖）按批交付、每项带验收。

## 0. 总原则

1. **每个交互都必须有真实后端语义**：引擎不支持的能力（视图、FK、分区等）在 GUI
   显式禁用/提示，不生成假 SQL、不静默成功。
2. **优先"每天都会用"的细节**：结果网格、SQL 编辑器、对象树、连接管理、导入导出；
   面板数量不再增加。
3. **深度对标方式**：逐项拆到"Navicat 的操作路径 → Studio 现状 → 差距 → 实现点"。
4. 破坏性操作（DROP/TRUNCATE/批量提交）必须二次确认 + 明确影响范围。
5. 每批必须有：offscreen 自动化测试 + 真实 GUI 证据 + 回归（P0–P3 测试全绿）。

## 2. 执行批次（GUI 侧）

### G1（1–2 周，本批立即执行；与 E1 引擎兼容并行）
1. **结果网格细节**：排序箭头/右键排序、列筛选菜单（本列/值列表）、列可见性、单元格详情、
   复制子菜单（含表头/INSERT/CSV）、选中行导出、列统计。
2. **SQL 编辑器细节**：查找/替换（Ctrl+F/Ctrl+H，正则/大小写/全词）、跳行、注释切换、
   复制行、移动行、执行光标语句。
3. **对象树对象管理**：新建/删除库、表设计器、重命名表、导入/导出入口、列节点操作。
4. **连接管理**：编辑/复制/删除连接（含确认与错误显式）。
5. **导入**：XLSX/JSON 导入（列映射/预览/失败行报告，复用现有分块导入框架）。
6. 全部动作：破坏性二次确认、引擎不支持能力显式提示；新增 `tests/test_studio_navicat_g1.py`。

### G2（2–4 周）
1. 连接：导入/导出连接、SSL CA/客户端证书、连接颜色、SSH 隧道（依赖 paramiko，先显式禁用）；
2. 编辑器：函数补全/`表.` 上下文/别名、执行选中、片段保存、历史搜索；多窗口/布局保存；
3. 数据：JSON/SQL 导出、SQL dump 导入、跨连接结构同步执行；
4. 运维：用户/权限 GUI、服务器监控增强、可视化 EXPLAIN、统一任务列表；
5. 拖拽生成 SQL。

### G3（持续）
1. 大结果集 QAbstractTableModel 完整虚拟化（10 万行）；
2. 数据生成器、快捷键自定义、二进制/图片查看器；
3. 多标签/多窗口拖拽、布局市场模板；
4. Navicat 对比 UX 走查（截图对照）→ 细节清单闭环。

## 3. 引擎依赖（E1/E2，与 GUI 并行；否则 GUI 只能"显式禁用"）

- **E1（P4-A，1–2 周）✅ 已完成 2026-10-21**：SHOW 元数据兼容（TABLE STATUS/FULL COLUMNS/
  FULL TABLES/COLLATION/CHARSET/CHARACTER SET/ENGINES/WARNINGS，列名对齐 MySQL 5.7、
  值真实不编造）；静默语义消除（PARTITION BY/存储过程原本已实现，改为 SHOW CREATE 如实
  回显、CALL 返回结果集、多结果集显式 1235；表选项 ENGINE=InnoDB→1064、CHARSET=gbk→1115、
  COLLATE→1273、AUTO_INCREMENT/ROW_FORMAT/ON UPDATE→显式错误、生成列赋值→3105）；
  字符集严格化（非法 UTF-8→1366，不落 U+FFFD；SET NAMES 校验)；SAVEPOINT/RELEASE/
  ROLLBACK TO 全实现。验证：18 个新测试 + mysql 5.0 老客户端元数据序列实跑通过
  （SHOW COLLATION/CHARSET/ENGINES/TABLE STATUS/FULL COLUMNS/FULL TABLES/WARNINGS 均 OK）。
  **已知限制**：UPDATE/DELETE 回滚到 SAVEPOINT 后再 COMMIT 的崩溃恢复暂缺补偿 WAL
  （进程内可见性正确）；`ENGINE=InnoDB` 显式拒绝（mysqldump 恢复需先剥离选项）。
- **E2（后续）**：CREATE INDEX/VIEW、ALTER MODIFY COLUMN、视图/索引纳入对象树与导出、
  FK 产品决策（当前明确拒绝 → GUI 禁用外键设计入口并提示）。

## 6. 明确不做（Navicat 有但本阶段不做）

- 完整数据同步/传输套件（先做结构同步 + 单表/查询迁移）；
- SSH/HTTP 隧道全参数（先显式禁用 + 依赖说明，再按需求实现）；
- BI/报表平台级能力（已有报表模板，不再扩展）；
- 多光标/列编辑、对象模型设计器、版本控制集成（G3 之后按反馈）。
