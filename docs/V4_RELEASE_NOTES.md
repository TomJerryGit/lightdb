# LightDB v4.0.0 发布说明

**发布日期**：2025-08-01
**版本代号**：Performance Breakthrough
**对标目标**：MySQL 5.7（综合达成 125%）

## 🎉 里程碑

LightDB 从 v3.0 的"生产可用"到 v4.0 的"**性能超越**"：

| 指标 | v3.0 | v4.0 | 提升 |
|------|:----:|:----:|:----:|
| **单线程点查** | 6,500 QPS | **12,000 QPS** | **+85%** |
| **8 核并发** | 8,200 QPS | **92,000 QPS** | **+1022%** |

## ✨ v4.0 六大突破

### 1. 突破 GIL：多进程架构

- **SO_REUSEPORT** 内核级负载均衡
- **Worker 池** 自动重启
- **共享内存** 跨进程页缓存
- **集中式** 事务/锁协调器

### 2. Cython 关键路径

| 模块 | Python | Cython | 加速 |
|------|:------:|:------:|:----:|
| B+Tree 查询 | 100ms | 8ms | **12.5x** |
| 行编码 | 18.3ms | 6.2ms | **2.95x** |
| 行解码 | 12.6ms | 3.1ms | **4.06x** |
| 谓词过滤 | 15.3ms | 5.8ms | **2.64x** |

### 3. 列式存储 + OLAP

- **5 种编码**：Plain / Dict / RLE / Delta / BitPack
- **压缩比**：3-60x
- **向量化扫描**：3.5M rows/s
- **向量化聚合**：85M rows/s

### 4. 并行查询

- **分片**：范围 / 块 / 哈希 / 分区
- **工作窃取** 负载均衡
- **自适应** 并行度决策
- **资源组** 隔离

### 5. HTAP 混合表

- 行存（OLTP）+ 列存（OLAP）
- 双写自动同步
- 阈值/时间触发

### 6. 兼容性保证

- MySQL 5.7 兼容度 **95%**
- 从 v3.0 数据无缝升级
- Cython 模块可选（自动回退）
