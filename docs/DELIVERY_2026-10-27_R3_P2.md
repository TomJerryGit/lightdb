## 3. 二进制快照备份/恢复（beta.94，`0c0f304`）

- `lightdb/backup/snapshot.py` + `scripts/snapshot_backup.py` / `snapshot_restore.py`
- 流程：每表 checkpoint（脏页/BTree 根 fsync + WAL 截断）→ 校验 WAL 全 0 → 拷贝
  `.dat/.btroot/.free/.autoinc/.wal/_meta.json/root.password` → manifest（版本/表/行数/
  SHOW CREATE/首尾样本/自增/SHA256/大小）；
- 恢复：版本+SHA256 全量校验（失败不触碰目标）→ 拷贝 → 逐表自检（行数/关键值/
  SHOW CREATE/自增/WAL=0）；目标非空默认拒绝（`--force` 旧目录改名保留）；
  服务监听默认 exit 3 拒绝（`--force` 仅告警，非在线热备——文档明示）；
  单表快照支持（仅恢复到空/新目录）；跨版本默认拒绝。
- 实测：10k 行 快照 3.27s/600.8KB、恢复+自检 3.65s；100k 行 快照 65.86s/6.14MB、
  恢复+自检 43.69s（瓶颈为引擎采集/校验查询；拷贝+SHA256 <1s）。
- 测试 12 passed / 1 skip（100k 档默认 skip）；回归 54 passed / 1 skipped；compileall PASS。
