# LightDB 限制声明（1.0）

> 本文件回答"能不能用/能用到什么程度"。所有数字都是**承诺上限**，超过即不在支持范围。
> 与 `docs/POSITIONING.md` 配套使用。

## 1. 部署与容量

| 项 | 上限 / 说明 |
|---|---|
| 部署形态 | 单机 Windows x64；一个数据目录只能被一个进程打开 |
| 数据量 | **≤ 20 GB**（数据 + 索引 + WAL） |
| 单表行数 | ≤ 1000 万行（宽表更少；取决于行宽与索引） |
| 单表列数 | ≤ 100（含索引列） |
| 索引 | 单列/多列二级索引；复合主键 2–8 列（每列 signed-32）；LIKE 前缀可走索引 |
| 文件系统 | 本地 NTFS；不支持网络盘/共享盘作为数据目录 |
| 内存 | 建议 ≥ 4 GB 可用；数据量接近上限时建议 ≥ 8 GB |

## 2. 并发与性能

| 项 | 上限 / 说明 |
|---|---|
| 连接数 | ≤ 50（默认连接池上限 100） |
| 并发写 | **≤ 10**（表级锁 + 单事务提交刷盘，超过后延迟上升） |
| 写入吞吐 | ≤ 200 简单写入/秒（单行 INSERT/UPDATE） |
| 点查 P99 | 10 万行级表、有索引：≤ 10 ms（本机 SSD） |
| 大结果集 | UI 虚拟化支持 10 万行展示；导出为分块同步 |
| 备份窗口 | 快照期间需**短暂静默**（写停顿），10 GB 约数秒至数十秒 |

> 实测参考（见 `docs/` 与 benchmarks）：16 客户端并发写效率约 3.4–6.5%（**不承诺**），
> 分片原型/组提交等仅为实验，不属于本版本支持能力。

## 3. SQL / 兼容性

- **支持**：单机 ACID 事务、SAVEPOINT、常用 DDL/DML、视图、二级索引、
  information_schema 基础表、SHOW 系列（常用形态）、PREPARE/EXECUTE、
  CHECK 约束、单列外键（RESTRICT）、基础触发器（BEFORE/AFTER × I/U/D，一层）
- **不支持（显式报错）**：FULLTEXT/SPATIAL 索引、多列外键/CASCADE、递归触发器、
  存储过程完整语法、窗口函数完备集、WITH CTE 复杂形态、JSON 完整函数集、
  `INSERT ... SELECT` 的复杂形态、`ON DUPLICATE KEY UPDATE` 部分形态
- **客户端**：Navicat / DBeaver / SQLAlchemy / JDBC / mysql CLI **基础用法**通过；
  未做全量 ORM/框架验证，复杂框架特性可能不被支持

## 4. 备份与恢复

- 支持：二进制快照（全量）、增量备份链（基线 + 行级差分增量）、逻辑 dump
- 备份需要**数据目录静默**（服务运行中会拒绝或提示停止）
- 恢复是先恢复到 staging 并逐表校验后安装；失败不破坏目标目录
- **必须自行定期演练恢复**；本软件不保证备份可用于任何特定 RPO/RTO

## 5. 运维与安全

- 认证：用户名/口令（支持 root.password / 环境变量）、SSL、SSH 隧道（内置 paramiko）
- 审计/慢查询日志、`/metrics`（默认仅回环，无鉴权；不要直接暴露公网）
- 无在线升级/回滚工具链（提供手工步骤与脚本）；升级前必须备份
- 安装包**未签名**（SmartScreen 可能提示），发布提供 SHA256

## 6. 平台与发布

- 仅 Windows 10/11 x64（已验证 Win10 22H2；其他版本未系统验证）
- 无 MSI / 无自动安装更新 / 无代码签名
- 单机 CI 与开发同机，发布流程为手工 + 脚本

## 7. 明确不支持的使用方式

- 作为关键业务主库（资金、医疗、合规数据）
- 多节点共享同一数据目录
- 通过公网直接暴露 MySQL 端口（无生产级防护/审计保证）
- 高并发写入服务、批量导入 >100 万行/次
- 在线 DDL 期间承载业务读写

## 8. 持久性档位（与 DURABILITY_MATRIX 一致）

- 单行 autocommit：**进程硬杀不丢**（WAL flush 到 OS）；**掉电可能丢最后若干条**（未 fsync）
- 多行 `INSERT ... VALUES (...),(...)`：同 autocommit 档位（语句级 flush，不 fsync）
- 显式 `BEGIN ... COMMIT`：COMMIT 会 fsync，**掉电不丢已提交**
- 需要"掉电不丢"的关键写入请使用显式事务；每次发布前跑
  `python scripts/crash_matrix.py --iterations 3`
- 场景、实测结果与已修复缺陷见 `docs/DURABILITY_MATRIX.md`
