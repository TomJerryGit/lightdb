## 本次修复的 CI 根因（beta.133–138）

1. **metrics 采集挂起**：`_collect_server_metrics()` 调用 `psutil.open_files()`
   在 Windows 上枚举句柄可阻塞数分钟 → 改用 `num_handles()`，精确列表需显式
   `LIGHTDB_METRICS_OPEN_FILES=1`（beta.133）。
2. **GUI smoke 失败**：`QTimer.singleShot(0, self.do_startup_restore)` 捕获绑定方法，
   测试构造后覆盖 `do_startup_restore` 无效，`auto_connect=False` 仍执行恢复并改写
   状态栏文案 → 改为经 `_run_startup_restore()` 间接调用（beta.138）。
3. **复制测试顺序相关失败**：全量顺序下 `selectRow` 不产生 `selectedRanges` →
   `copy_selection` 无选中时回退当前单元格；测试用 selectionModel 显式选行（beta.134）。
4. **Qt ABI 污染**：共享系统 Python 上 shiboken6 被单独升级（6.12）与 PySide6 6.6.0
   不兼容 → QtCore DLL 加载失败、整套 Qt 测试在 `pytest_configure` 崩溃：
   - `pyproject.toml` 精确 pin `PySide6==6.6.0` + `shiboken6==6.6.0`（beta.135）
   - CI 安装步骤强制 `--force-reinstall --no-deps` 校正并 import fail-fast（beta.136）
5. **CI 安装卡死**：每次 `pip install -e ".[all,dev]"` 联网解析依赖，网络抖动时卡住
   → 依赖已在 runner 预装，改为 `--no-deps` 只装项目本体 + 关键依赖自检回退（beta.137）。
