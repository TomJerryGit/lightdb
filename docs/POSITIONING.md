# LightDB 产品定位（免费 / 轻量 / 本地优先）

> 本文件是**对外承诺的唯一定位来源**。营销文案、README、Release Notes、Issue 回复
> 与代码里的"支持/不支持"表都以此为准；超出本文范围的承诺视为 Bug。

## 一句话定位

**LightDB 是一个免费的、本地优先的 MySQL 兼容轻量数据库 + 管理工具（Studio/Web），
面向学习、个人项目、内部小工具和单机应用；不适合作为关键业务数据库。**

## 目标用户

| 用户 | 典型场景 |
|---|---|
| 学习者/学生 | 数据库原理、MySQL 兼容性实验、课程设计 |
| 个人开发者 | 桌面/单机应用自带数据库、原型验证、离线环境 |
| 小型团队内部工具 | 单机部署的小工具、报表、配置库（非核心数据） |
| 迁移演练 | 练习 MySQL 备份/迁移/兼容性检查 |

## 承诺支持（1.0）

- 单机部署（Windows x64）；桌面 Studio + Web 管理 + MySQL 协议连接
- 基础 DDL/DML、单机事务、二级索引、视图、权限、审计、慢查询
- 全量二进制快照备份 / 恢复；增量备份链（CLI + Studio/Web 入口）
- MySQL 子集兼容：Navicat、DBeaver、SQLAlchemy、JDBC、mysql CLI 的**基础用法**
- 明确的错误提示（不支持的功能显式报错，不静默丢弃）

## 明确不承诺（1.0 起长期有效）

- ❌ 高可用、自动故障切换、多主、集群、分布式事务
- ❌ 高并发 OLTP（>10 并发写）与大吞吐（>200 写/秒）
- ❌ 大容量（>20 GB）与复杂分析查询
- ❌ 完整 MySQL 兼容（触发器/外键/CHECK 仅为 MVP；无 FULLTEXT、无完整存储过程）
- ❌ 在线 DDL、在线升级、热备份（备份需短暂静默窗口）
- ❌ 关键业务数据、金融/医疗等强合规场景
- ❌ SLA、赔偿、企业级支持
- ❌ 代码签名（SmartScreen 可能提示；安装说明提供 SHA256 校验）

## 更新与支持模型

- 发布：GitHub Releases（安装包 + 便携 zip + SHA256 + Release Notes）
- 版本节奏：**每季度一个稳定版**；只修 Bug，不追新功能
- 支持：GitHub Issues，**best-effort，无 SLA**；FAQ 与手册优先于一对一答复
- 无遥测：不收集任何使用数据；自动更新检查可关闭

## 与 MySQL 的关系

LightDB 使用 MySQL 线协议并实现其**子集**，便于用现有客户端连接、便于迁移演练；
它不是 MySQL 的替代品，也不保证应用可以零改动迁移。
